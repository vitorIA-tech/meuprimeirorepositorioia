O aprendizado de máquina funciona como a educação de um cérebro digital, onde ensinamos um computador a resolver problemas de três maneiras diferentes.

**Aprendizado Supervisionado (O Professor que dá a Resposta)**

* **Como funciona:** Você entrega o material de estudo para o computador, mas já dá o gabarito junto. O computador olha para o exemplo e para a resposta certa, aprendendo a regra para acertar as próximas vezes sozinho.
* **Exemplo Prático:** Você mostra 100 fotos para o computador. Em 50 delas, você diz: "Isso é um gato". Nas outras 50, você diz: "Isso é um cachorro". Quando você mostrar a foto número 101, ele vai usar o que aprendeu com as fotos anteriores para adivinhar corretamente se é um gato ou um cachorro.

**Aprendizado Não Supervisionado (O Detetive de Padrões)**

* **Como funciona:** Você entrega um monte de informações misturadas para o computador, sem explicar o que é cada coisa e sem dar nenhum gabarito. O trabalho dele é organizar a bagunça encontrando semelhanças escondidas.
* **Exemplo Prático:** Você dá uma caixa gigante cheia de peças de LEGO misturadas para o computador. Ninguém diz a ele o que é uma janela, uma roda ou um telhado. Sozinho, explorando as peças, ele percebe os formatos e as separa em três montes: um só com peças vermelhas, outro com peças retangulares e outro com peças redondas.

**Aprendizado por Reforço (O Jogador de Videogame)**

* **Como funciona:** O computador aprende puramente por tentativa e erro. Se ele faz algo bom, ganha pontos (uma recompensa). Se faz algo ruim, perde pontos (um castigo). O único objetivo dele é descobrir qual sequência de ações gera a maior pontuação possível.
* **Exemplo Prático:** Você coloca o computador para jogar *Super Mario* sem explicar para que servem os botões. Ele aperta um botão e o Mario anda para frente (ganha 1 ponto). Ele aperta outro, o Mario cai no buraco (perde 10 pontos). Ele tenta de novo e aperta o botão de pular antes do buraco (ganha 5 pontos). Depois de errar várias vezes, ele descobre sozinho como passar a fase inteira sem morrer só para acumular a pontuação máxima.
